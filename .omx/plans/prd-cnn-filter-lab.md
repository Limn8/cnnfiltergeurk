# CNN Filter Scratch Lab PRD

## 1. Purpose

학생들이 CNN의 3x3 합성곱 필터가 이미지의 픽셀 주변값을 어떻게 읽고, 행렬곱 합산을 통해 새로운 픽셀값을 만드는지 직접 체험하는 웹앱을 만든다.

핵심 경험은 "이미지를 긁어보며 계산을 드러내는 실습"이다. 사용자는 이미지를 업로드하고 필터를 선택한 뒤, 마우스를 누른 채 이미지 위를 드래그한다. 드래그한 위치마다 선택된 3x3 커널이 적용되고, 해당 위치의 원본 픽셀 3x3 영역, 필터 행렬, 곱셈 결과, 합산값, 처리된 이미지 결과가 함께 표시된다.

## 2. Target Users

- 중고등학생 또는 대학 초급 수준의 AI/CNN 입문 학습자
- 수업 중 시연하는 교사
- 픽셀, 행렬, 필터의 관계를 시각적으로 이해하고 싶은 학습자

## 3. Learning Goals

- 3x3 필터가 중심 픽셀 주변의 9개 값을 사용한다는 점을 이해한다.
- 각 이미지 픽셀값과 필터값을 자리별로 곱한 뒤 합산한다는 점을 이해한다.
- 세로선 강조, 가로선 강조, 경계 검출 같은 커널이 서로 다른 결과를 만든다는 점을 비교한다.
- CNN의 필터가 전체 이미지를 한 번에 마법처럼 바꾸는 것이 아니라, 작은 영역을 훑으며 반복 계산한다는 점을 체험한다.

## 4. Core User Flow

1. 사용자가 웹앱을 연다.
2. 사용자가 이미지 파일을 업로드한다.
3. 앱이 이미지를 캔버스에 표시한다.
4. 사용자가 제공된 3x3 필터 중 하나를 선택한다.
5. 사용자가 이미지 위에서 좌클릭한 채 드래그한다.
6. 드래그한 위치 주변의 3x3 픽셀값이 추출된다.
7. 선택된 필터 행렬과 픽셀 행렬의 자리별 곱셈 결과가 표시된다.
8. 합산값이 출력 픽셀값으로 정규화되어 결과 이미지에 반영된다.
9. 사용자는 긁은 영역이 점차 필터 처리된 이미지로 바뀌는 것을 본다.

## 5. Functional Requirements

### 5.1 Image Upload

- 사용자는 로컬 이미지 파일을 업로드할 수 있어야 한다.
- 지원 형식: PNG, JPEG, WebP.
- 앱은 업로드 이미지를 캔버스에 맞게 표시하되, 계산은 내부 캔버스 픽셀 데이터를 기준으로 수행한다.
- 너무 큰 이미지는 실습 성능을 위해 긴 변 기준 최대 900px 정도로 축소한다.

### 5.2 Filter Selection

기본 제공 필터는 학생들이 결과 차이를 즉시 비교할 수 있도록 여러 성격의 커널을 제공한다. 필터 목록은 "기본", "흐림", "윤곽/선", "효과" 그룹으로 나누어 제시한다.

| Filter | Kernel |
| --- | --- |
| 엣지 검출 | `[1, 0, -1; 1, 0, -1; 1, 0, -1]` |
| 선명화 | `[0, -1, 0; -1, 5, -1; 0, -1, 0]` |
| 블러 | `[1/9, 1/9, 1/9; 1/9, 1/9, 1/9; 1/9, 1/9, 1/9]` |
| 가우시안 블러 | `[1, 2, 1; 2, 4, 2; 1, 2, 1] / 16` |
| 수직선 강조 Sobel | `[-1, 0, 1; -2, 0, 2; -1, 0, 1]` |
| 수평선 강조 Sobel | `[-1, -2, -1; 0, 0, 0; 1, 2, 1]` |
| 강한 경계 검출 | `[-1, -1, -1; -1, 8, -1; -1, -1, -1]` |
| 외곽선 검출 | `[0, 1, 0; 1, -4, 1; 0, 1, 0]` |
| 엠보싱 | `[-2, -1, 0; -1, 1, 1; 0, 1, 2]` |
| 밝은 엠보싱 | `[-1, -1, 0; -1, 0, 1; 0, 1, 1]` + offset `128` |
| 모션 블러 | `[1, 0, 0; 0, 1, 0; 0, 0, 1] / 3` |
| 박스 블러 강하게 | `[1, 1, 1; 1, 1, 1; 1, 1, 1] / 9` |
| 중심 강조 | `[0, -0.5, 0; -0.5, 3, -0.5; 0, -0.5, 0]` |
| 어두운 테두리 | `[1, 1, 1; 1, -7, 1; 1, 1, 1]` |
| 반전 느낌 경계 | `[0, -1, 0; -1, 4, -1; 0, -1, 0]` |

- 필터는 버튼 또는 카드 형태로 선택한다.
- 선택된 필터의 3x3 행렬이 항상 화면에 표시되어야 한다.
- 각 필터 카드에는 "무엇이 재밌게 보이는지"를 한 줄로 표시한다.
- 예: "머리카락과 창틀이 또렷해져요", "사진이 도장처럼 보여요", "살짝 입체감이 생겨요".
- 사용자는 "직접 만들기" 영역에서 3x3 행렬의 9개 성분을 숫자로 입력해 커스텀 필터를 적용할 수 있다.
- 커스텀 필터는 정수와 소수 입력을 허용한다.
- 커스텀 필터 입력값이 바뀌면 즉시 선택 가능한 필터로 반영된다.
- 사용자는 커널 크기를 `1x1`부터 `15x15`까지 홀수 단위로 조절할 수 있다.
- 기본 필터는 커널 크기에 맞춰 교육용 N x N 커널로 확장된다.
- 커스텀 필터 입력 행렬도 선택한 커널 크기에 맞춰 N x N으로 확장된다.

### 5.3 Scratch Interaction

- 사용자가 원본 이미지 캔버스에서 마우스 왼쪽 버튼을 누르고 드래그하면 해당 경로를 따라 필터 처리가 진행된다.
- 터치 환경에서는 손가락 드래그를 지원한다.
- 브러시 반경은 기본 18px로 둔다.
- 브러시 반경은 사용자가 1px부터 42px까지 조절할 수 있다.
- 브러시가 지나간 영역만 결과 캔버스에 반영된다.
- 아직 긁지 않은 영역은 원본 이미지로 보이거나, 원본/결과 비교가 분명하도록 결과 레이어가 덮이지 않은 상태로 유지한다.

### 5.4 Convolution Calculation Display

드래그 중 현재 포인터 위치에 대해 다음을 실시간 표시한다.

- 중심 픽셀 좌표
- 중심 픽셀 주변의 3x3 원본 밝기값 또는 RGB 요약값
- 선택된 3x3 필터값
- 자리별 곱셈 결과 행렬
- 합산 전개식
- 정규화 및 클램프 후 최종 출력값

MVP 계산 표시 기준:

- 교육용 가독성을 위해 계산 패널은 grayscale 밝기값 기준으로 표시한다.
- 실제 결과 이미지는 RGB 각 채널에 같은 커널을 적용한다.
- 값은 `0..255` 범위로 클램프한다.
- 블러 필터처럼 스케일이 필요한 필터는 `divisor`를 적용한다.

### 5.5 Result Visualization

- 원본 이미지 캔버스와 결과 이미지 캔버스를 나란히 또는 겹쳐서 비교할 수 있어야 한다.
- MVP 기본값은 단일 이미지 위에서 긁은 영역만 결과가 드러나는 방식이다.
- 보조 패널에는 전체 결과 캔버스 미리보기를 제공한다.
- "초기화" 버튼으로 긁은 결과를 지울 수 있어야 한다.
- "이미지 행렬" 토글을 켜면 전체 이미지를 대표 좌표로 샘플링한 밝기값 행렬을 볼 수 있다.
- 이미지 행렬 패널은 `원본 밝기값 → 현재 결과 밝기값` 형태로 표시하고, 긁어서 바뀐 셀은 강조한다.
- 실제 전체 픽셀을 모두 텍스트 행렬로 표시하면 지나치게 커지므로, MVP에서는 대표 좌표 샘플 행렬로 보여준다.

### 5.6 Educational UI

- 앱 안의 텍스트는 한국어를 기본으로 한다.
- 설명은 짧고 행동 중심이어야 한다.
- 수식 표시가 과도하게 길어지지 않도록 현재 위치의 3x3 계산만 보여준다.
- 학생이 직접 조작하는 화면이 첫 화면이어야 하며, 별도 랜딩 페이지는 만들지 않는다.

## 6. Non-Functional Requirements

- 브라우저에서 설치 없이 실행되어야 한다.
- 이미지 드래그 중 눈에 띄는 지연이 없어야 한다.
- 핵심 계산 로직은 테스트 가능하도록 UI와 분리한다.
- 모바일/태블릿에서도 최소한 업로드, 필터 선택, 드래그 실습이 가능해야 한다.
- 개인정보 보호를 위해 업로드 이미지는 서버로 전송하지 않고 클라이언트에서만 처리한다.

## 7. MVP Scope

MVP에 포함:

- React 기반 단일 페이지 앱
- 이미지 업로드
- 12개 이상의 기본 필터 제공
- 3x3 커스텀 필터 입력
- 브러시 크기 조절
- 커널 크기 조절
- 전체 이미지 행렬 보기 토글
- 캔버스 기반 scratch 처리
- 실시간 3x3 계산 패널
- 결과 미리보기
- 초기화 기능
- 핵심 합성곱 유틸 테스트

MVP에서 제외:

- 여러 레이어를 쌓는 CNN 구조 시뮬레이션
- 학습용 퀴즈/점수 시스템
- 이미지 저장/다운로드
- 서버 저장 또는 계정 기능

## 8. Proposed Information Architecture

- 상단: 앱 제목, 이미지 업로드, 초기화
- 왼쪽 또는 상단 패널: 필터 선택
- 중앙: 긁어보는 메인 이미지 캔버스
- 오른쪽 패널: 현재 3x3 계산 과정
- 하단 또는 보조 패널: 결과 이미지 미리보기

## 9. Technical Direction

- Stack: Vite + React + TypeScript
- Rendering: HTML Canvas 2D
- Core modules:
  - `filters`: 커널 정의, divisor, offset, label
  - `convolution`: 픽셀 샘플링, 커널 적용, 클램프
  - `canvas`: 이미지 로딩, 스케일링, 포인터 좌표 변환, scratch drawing
  - `ui`: 필터 선택, 계산 패널, 업로드 컨트롤
- Testing:
  - 커널 계산 단위 테스트
  - 경계 픽셀 처리 테스트
  - divisor와 clamp 테스트

## 10. Acceptance Criteria

- 사용자는 PNG/JPEG/WebP 이미지를 업로드할 수 있다.
- 사용자는 엣지 검출, 샤프닝, 블러, 가우시안 필터를 포함한 12개 이상의 기본 필터를 선택할 수 있다.
- 사용자는 커널 크기를 홀수 단위로 조절할 수 있고, 선택된 필터가 해당 크기의 커널로 적용된다.
- 사용자는 커스텀 행렬의 숫자를 직접 입력해 필터를 적용할 수 있다.
- 사용자는 브러시 크기를 조절해 한 번에 처리되는 픽셀 범위를 바꿀 수 있다.
- 사용자는 이미지 행렬 보기 패널을 켜고 끌 수 있다.
- 사용자가 이미지 위를 좌클릭 드래그하면 드래그한 영역에 선택 필터 결과가 나타난다.
- 드래그 중 현재 위치의 3x3 원본값, 필터값, 곱셈 결과, 합산값이 보인다.
- 결과값은 `0..255` 범위로 안정적으로 표시된다.
- 이미지 가장자리에서도 앱이 깨지지 않는다.
- 초기화 후 다시 실습할 수 있다.
- 빌드와 테스트가 통과한다.

## 11. Open Decisions

아래 항목은 구현을 막지는 않으며, 기본값으로 진행 가능하다.

- 계산 패널의 픽셀값을 grayscale만 보여줄지, RGB 채널별 탭을 제공할지
- 긁은 영역 표현을 원본 위 결과 레이어로 할지, 원본/결과 split-view로 할지
- 학생용 예시 이미지를 기본 내장할지
- 커스텀 필터에 divisor와 offset 입력까지 제공할지
- 전체 이미지 행렬을 대표 샘플이 아니라 실제 모든 픽셀로 내보내는 기능을 둘지

## 12. Default Decisions For Implementation

- 계산 패널은 grayscale 기준으로 간결하게 표시한다.
- 실제 결과 이미지는 RGB 채널별 합성곱을 적용한다.
- 첫 화면은 바로 실습 화면으로 구성한다.
- 샘플 이미지는 내장하지 않고 업로드 중심으로 시작한다.
- 커스텀 필터는 9개 커널 성분 입력까지만 MVP에 포함하고, divisor와 offset은 후속 기능으로 둔다.
